## درباره این تمرین

این ریپازیتوری میزبان تمرین سری اول درس «روش‌های محاسباتی در مهندسی برق» است. برگه تمرین شامل **۱۸ سؤال آموزشی + ۱ سؤال امتیازی + ۳ سؤال آزمون خود** است که از ساده‌ترین مفاهیم متلب شروع می‌شود و گام‌به‌گام تا مسائل ترکیبی گرایش‌های مختلف (قدرت، الکترونیک، کنترل و مخابرات) و رسم میدان‌های سه‌بعدی پیش می‌رود.

هر سؤال یک **کد QR** دارد که به ویدئوی آموزشی ۲ تا ۳ دقیقه‌ای همان سؤال (میزبانی‌شده در گوگل‌درایو) متصل است؛ در ویدئو، دستورها و سینتکس‌های متلبِ لازم برای آن سؤال آموزش داده می‌شود. سه سؤال آخر عمداً ویدئو ندارند و باید با ابزارهایی که در ۱۸ سؤال قبل یاد گرفته‌اید حل شوند.

## ساختار تمرین

| گام | سؤال‌ها | محتوا |
|---|---|---|
| ۱ — مبانی متلب | ۱ تا ۶ | عملگرها، متغیر و چاپ، ورودی/خروجی، بردارها، ماتریس‌ها، ضرب ماتریسی |
| ۲ — ریاضیات مهندسی | ۷ تا ۱۳ | exp و log، چندجمله‌ای‌ها، مشتق، انتگرال، حد، اعداد مختلط، لاپلاس |
| ۳ — قدم در گرایش‌ها | ۱۴ و ۱۵ | حلقه‌ها و کنترل سرعت ربات (کنترل)، تابع‌نویسی (الکترونیک) |
| ۴ — رسم نمودار | ۱۶ تا ۱۸ | plot و subplot و stem، bar و pie، سه‌بعدی با meshgrid و surf و contour |
| سؤال امتیازی | — | پرچم المپیک با تابع `getCircle` (بدون ویدئو) |
| ۵ — آزمون خود | ۱۹ تا ۲۱ | بدون ویدئو و بدون راهنما — فقط با آموخته‌های خودتان |

## نحوه تحویل

1. در این ریپازیتوری یک **Fork** بگیرید (دکمه Fork در بالا-راست صفحه).
2. در Fork خودتان با **Add file ← Upload files** فایل‌های `.m` حل را آپلود کنید.
3. با **Commit changes** ثبت کنید.
4. لینک Fork خودتان به‌همراه **نام و نام‌خانوادگی و شماره دانشجویی** را با موضوع «تمرین سری اول — نام — شماره دانشجویی» به ایمیل `arian13es@gmail.com` بفرستید.

### قالب نام‌گذاری فایل‌ها

```
Q<شماره سؤال>-<نام‌خانوادگی>-<شماره دانشجویی>.m
مثال:  Q05-Ahmadi-40215.m
```

## نکته‌ها

- پاسخ هر سؤال یک فایل M-file است؛ خروجی‌های عددی با `fprintf` و شکل‌ها در همان اسکریپت تولید شوند.
- جدول «خطاهای رایج تازه‌کارها» در ابتدای برگه تمرین را قبل از شروع ببینید.
- ویدئوهای آموزشی فقط سینتکس را آموزش می‌دهند؛ حل سؤال کار خود شماست.
